## Цель работы: Ознакомиться со средой разработки Android Studio, создать и запустить простое приложение, изучить структуру проекта и базовые элементы интерфейса.

---

## Ответы
**1. Основные компоненты структуры проекта:**

manifests: Содержит файл AndroidManifest.xml;

kotlin+java: Содержит исходный код на Java/Kotlin (пакеты, активности, классы) и тесты;

res: Ресурсы приложения (графика, макеты, строки, стили);

Gradle Scripts: Файлы сборки проекта.

**2. AndroidManifest.xml это файл конфигурации, который:**

Указывает системе имя пакета;

Описывает компоненты приложения (активности, службы, приемники вещания, контент-провайдеры);

Запрашивает разрешения;

Объявляет минимальную и целевую версии Android;

Содержит метаданные о приложении (иконка, тема, название).

**3. minSdkVersion:**
Минимальная версия Android, на которой приложение может быть установлено и работать.

**targetSdkVersion:**
Версия Android, на которой приложение тестировалось и для работы на которой оно оптимизировано.

**4. AVD (Android Virtual Device)** — это конфигурация виртуального устройства.
Он используется для запуска и тестирования приложений без наличия реального физического устройства.

**5. Нужно хранить текст в файле res/values/strings.xml,** присвоив ему уникальный идентификатор (например, <string name="hello">Привет</string>). В коде активность ссылается на этот идентификатор (R.string.hello), а в макете (layout) — через синтаксис @string/hello. Чтобы изменить текст, достаточно отредактировать файл strings.xml; код активности и макетов менять не нужно.
